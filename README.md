# Amazon Sales Performance Analysis and Interactive Dashboard using Power BI

This project focuses on analyzing Amazon sales data using Microsoft Power BI. Starting from a raw CSV dataset, I cleaned the data, transformed it using Power Query, created DAX calculations, and designed an interactive dashboard that helps understand sales performance, customer behavior, and business trends.

---

## 📌 About Project

Every online order generates valuable data, but raw data alone doesn't provide useful insights. In this project, I used a real-world Amazon sales dataset containing **50,001 records** and transformed it into an interactive Power BI dashboard.

The dashboard allows users to explore sales performance across different product categories, customer regions, payment methods, discounts, and ratings. It also includes a **3-month sales forecast** to provide a short-term view of future sales trends.

This project demonstrates the complete Business Intelligence workflow—from raw data to a clean, interactive, and decision-ready dashboard.

---

## 🎯 Project Objectives

- Analyze a real-world Amazon sales dataset.
- Clean and prepare the dataset using Power Query.

- Analyze sales by category, region, and payment method.
- Build a short-term sales forecast.
- Use DAX to create calculated columns for additional insights.

## 🧹 Data Cleaning & Preparation

Before creating the dashboard, I cleaned and prepared the dataset using Power Query.

The main steps included:

- Importing the CSV file into Power BI.
- Verifying data types for all columns.
- Checking for missing values.
- Removing duplicate records using Order ID.
- Validating date and numeric columns.
- Creating a DAX calculated column (**Review Category**) to classify products as **Popular** and **Less Popular**.

These steps helped ensure that the dashboard was built using accurate and reliable data.
